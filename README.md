# 🎙️ Telegram-бот транскрибации голоса

Бот расшифровывает голосовые и видеосообщения (кружки) в текст. Работает
полностью локально на CPU: Whisper для распознавания речи, silero_te для
восстановления пунктуации.

📋 **[SETUP_GUIDE.md](SETUP_GUIDE.md)** — полная инструкция по установке и настройке.

## 🎯 Возможности

- **Голосовые сообщения** → транскрибация с восстановлением пунктуации
- **Видеосообщения (кружки)** → извлечение аудио + транскрибация
- Ответ приходит цитатой (`blockquote expandable`), длинный текст разбивается
  на части по границам предложений
- **Ссылки на Instagram** (посты, reels, карусели) → бот отвечает самим видео
  или альбомом фото. В личке работает сразу, в группах включается командой
  `/instagram on`. Публичные посты качаются без логина (yt-dlp, запасной путь —
  InstaFix). Видео больше
  50 МБ и фото больше 10 МБ сжимаются под лимиты Telegram. Если видео доступно
  только без звука, оно отправляется без звука с предупреждением в подписи

Текстовые сообщения бот не сохраняет; читает их только в чатах с включённым
Instagram (в личке — по умолчанию) — чтобы найти ссылки. На диск попадают только временные файлы
(аудио, медиа из Instagram), которые удаляются сразу после обработки.

## 💬 Команды

| Команда | Доступ | Описание |
|---------|--------|----------|
| `/start` | все | Справка |
| `/status` | админ | Модель, устройство, язык, загружена ли модель в память |
| `/instagram` | все | Показать, включена ли загрузка из Instagram в чате |
| `/instagram on\|off` | админ чата | Включить/выключить загрузку из Instagram в этом чате (в личке включено по умолчанию) |

Транскрибация команд не требует — просто отправьте боту голосовое или кружок.

## 🛠️ Технологии

| Задача | Решение |
|--------|---------|
| Транскрибация | Faster-Whisper (CTranslate2), `large-v3-turbo`, int8 |
| Пунктуация | silero_te (torch.hub) + `initial_prompt` для Whisper |
| Instagram | yt-dlp (без логина), запасной путь — InstaFix; ffmpeg (H.264, сжатие) |

### Модели Whisper

| Модель | Размер на диске | Загрузка в ОЗУ | Рекомендация |
|--------|-----------------|----------------|--------------|
| `large-v3-turbo` | 1.6 GB | 4 с | **Рекомендуется** |
| `large-v3` | 2.9 GB | — | Вдвое больше и медленнее при том же WER |
| `medium` | 769 MB | — | Только для очень слабых систем |

## 📋 Системные требования

| Ресурс | Минимум | **Рекомендуется** |
|--------|---------|-------------------|
| vCPU | 2 | **4** |
| ОЗУ | 3 GB | **4 GB** |
| Диск | 8 GB | **12 GB** |

Фактическое потребление процесса бота:

| Стадия | RSS |
|--------|-----|
| Запуск, модель ещё не загружена | 51 MB |
| Модель Whisper загружена | 1181 MB |
| Во время транскрибации | 1378 MB |
| **Пик (Whisper + silero_te)** | **1866 MB** |

Модель грузится лениво — до первого голосового сообщения бот занимает ~50 МБ.

### Скорость транскрибации

Замер на 40с непрерывной речи (VAD не срезал паузы — худший случай):

| vCPU | `WHISPER_BEAM_SIZE=1` | `WHISPER_BEAM_SIZE=5` |
|------|----------------------|----------------------|
| 2 | 36.7 с (1.08× RT) | 52.2 с (0.76× RT) |
| 4 | 32.8 с (1.21× RT) | 35.2 с (1.13× RT) |
| 8 | **26.5 с (1.49× RT)** | 35.7 с (1.11× RT) |

Выводы из замеров:

- **Масштабирование по ядрам слабое:** 2 → 8 vCPU даёт лишь +38% скорости.
  Больше 4 vCPU почти не окупается.
- **`beam_size=1` быстрее `beam_size=5`** на 26% при 8 ядрах, а на реальной речи
  расшифровка выходит идентичной. Если важна скорость — ставьте 1.
- На реальных голосовых с паузами VAD срезает 20–40% длительности, поэтому
  фактическое время обычно меньше приведённого.

- **Python:** 3.10+
- **ОС:** Ubuntu 24.04 LTS (рекомендуется)
- **CPU:** x86-64 с AVX2 (обязательно — без него в 2–3 раза медленнее)

## 🚀 Быстрый старт

```bash
# 1. Зависимости. torch — ОБЯЗАТЕЛЬНО CPU-сборка: CUDA-вариант тянет
#    ~4.4 GB лишних библиотек NVIDIA, которые на CPU-сервере не нужны.
pip3 install torch --index-url https://download.pytorch.org/whl/cpu
pip3 install -r requirements.txt

# 2. Конфигурация
cp example.env .env
vi .env          # укажите BOT_TOKEN и ADMIN_USER_IDS

# 3. Проверка целостности
python3 run_tests.py

# 4. Запуск
python3 bot.py
```

Модель Whisper (1.6 GB) скачается при первом голосовом сообщении,
silero_te (128 MB) — при первом восстановлении пунктуации.
